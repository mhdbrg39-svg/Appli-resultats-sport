# Résultats Sport

Application web en français pour suivre les résultats et les classements :

- Ligue 1
- Premier League
- La Liga
- Bundesliga
- NBA

## Fonctionnalités

- Matchs du jour, avec navigation jour par jour
- Scores en direct, mis à jour automatiquement toutes les 30 secondes
- Classements (par conférence pour la NBA)
- Heures affichées à l'heure de Paris

Tout le code est dans `index.html`. Les données viennent d'ESPN.
